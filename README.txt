HOW TO PUBLISH
1. Upload index.html, style.css, app.js and favicon.svg together into your hosting site's public root folder.
2. Replace YOUR-DOMAIN-HERE in the canonical link in index.html with your real domain.
3. Search Console: paste the exact meta verification token Google gives you into the commented google-site-verification meta tag in the <head>, then publish and click Verify in Search Console. Never use a made-up token.
4. Firebase gallery admin (optional): create Firebase project, enable Email/Password Authentication, Firestore and Storage. Copy the Firebase web config into app.js. Create an admin user, replace YOUR_ADMIN_EMAIL in the rules, and publish Firestore and Storage rules separately.
5. Test on mobile: call button, WhatsApp button, menu and gallery.

- Website is usable as a static site without Firebase; Firebase is needed for photo upload/delete admin features.
